# practice-project

This is your practice sandbox for the exercises in the Claude Code Learning Platform.

It's a small, deliberately unpolished static website — plain HTML, CSS, and JavaScript,
no build step. Just open `index.html` in a browser to see it.

To use it: open a **separate** Claude Code session with this folder (`practice-project/`)
as the working directory, and follow the exercises in each lesson of the course.

You'll notice this folder doesn't have a `CLAUDE.md` or a `.claude/` folder yet —
that's on purpose. The Foundations and Extending modules have you create those yourself.
